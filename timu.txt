一、考核目标
考核 ROS 组成员独立完成移动机器人仿真环境搭建、二维地图构建、地图保存与加载、定位及自主导航的能力。考核以可复现的仿真运行结果、代码配置和现场讲解作为评分依据。

二、考核任务
在自建的室内仿真场景中，搭建一台具备差速运动、二维激光雷达和里程计的移动机器人。机器人从空白地图开始完成环境建图，保存地图文件；随后重新启动定位与导航流程，加载已保存地图并完成指定目标点导航。
1. 搭建仿真场景与机器人模型，保证机器人可在场景中移动，激光雷达、里程计及坐标变换数据正常发布。
2. 通过遥控或等效方式驱动机器人覆盖场景，生成二维栅格地图，并保存地图图像、地图元数据及相关配置。
3. 结束建图流程后，重新启动系统并加载保存的地图，完成机器人定位；在可视化界面检查地图、激光扫描和机器人位姿之间的对齐情况。
4. 依次执行现场指定的 n 个导航目标点，展示全局路径、局部避障和到点停车。目标点至少覆盖直行、转弯及绕开障碍物的场景。
5. 现场说明系统节点与话题、坐标系关系、建图和导航配置，并解释遇到的问题及定位过程。

三、现场验收标准
验收项
合格表现
仿真启动
场景与机器人可重复启动；机器人运动、激光数据、里程计和必要的 TF 坐标变换可观察
地图生成
地图由现场运行产生，覆盖指定测试区域；墙面轮廓连续、主要通道清晰，地图图像和元数据成功保存
地图加载与定位
新一轮运行能加载已保存地图；机器人位姿稳定，激光扫描与地图边界基本重合；坐标变换链路完整
导航执行
按顺序执行 n 个目标点，至少 n-1 个目标在限时内到达；规划路径清晰，遇到障碍时能调整路线或安全停止，全程碰撞次数少于 2 次
到点判定
验收阈值采用组内统一标准；组内发布的具体标准优先执行，基础标准为目标位置误差 ≤ 0.25 m、朝向误差 ≤ 15°，单个目标限时 60 秒
复现与讲解
按 README 中的命令可启动关键流程；能指出主要配置文件，并说明地图、定位、规划和控制之间的关系
四、提交材料
- 完整工程源代码，包含仿真场景、机器人模型、启动文件和参数配置。
- 现场生成的地图图像与元数据文件，以及加载地图所需的配置。
- README：列出软件版本、依赖、启动建图、保存地图、启动定位导航和发送目标点的步骤。
- 运行证据：仿真场景、生成地图、定位对齐、路径规划与目标完成状态的截图；录屏建议控制在 3 分钟内。
- 第三方功能包或参考项目的来源说明，以及本人编写、配置、集成和调试的内容。
